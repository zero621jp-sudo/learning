# 情報処理安全確保支援士 科目A ドリル

IPA が公開している情報処理安全確保支援士試験の過去問題（令和5〜7年度 春期・秋期）を、ブラウザで解けるクイズにしたものです。
iPhone・iPad・PC のブラウザで動きます。インストールは不要です。

- **科目A-1（旧 午前Ⅰ）**：6回分 × 30問 = 180問
- **科目A-2（旧 午前Ⅱ）**：6回分 × 25問 = 150問

## 機能

| 項目 | 内容 |
|---|---|
| 出題範囲 | 年度・回を1つ選ぶ／複数の回からランダムに出題する「ミックス」 |
| 科目 | A-1、A-2、両方（A-1＋A-2） |
| 本番モード | A-1：30問・50分、A-2：25問・40分、両方：55問・90分 |
| 集中小テスト | 25分（A-1：15問、A-2：16問） |
| サクッと | 10分（6問） |
| カスタム | 5〜90分。問題数は本番と同じ1問あたりの時間（約1.6〜1.7分）で自動計算 |
| タイマー | 残り時間を画面上部に常に表示。残り時間が少なくなると色が変わり、0になると自動で採点 |
| 採点 | 100点満点に換算。合格ラインは基準点の60点（両方を解いた場合は、A-1・A-2がそれぞれ60点以上で合格） |
| 合格予想 | 合格予想点数（本番の問題数に換算、80%区間つき）と合格率（本番で60点以上をとる確率）を、今回の結果と累計の結果からそれぞれ計算 |
| 弱点分析 | 問題を15分野（セキュリティは4分野に細分）に分類し、分野ごとの正答率を「今回」「累計」で表示。正答率60%未満の分野を弱点として示し、「練習」でその分野の問題だけを10問演習（未出題・前回不正解の問題を優先） |
| その他 | 1問ごとの答え合わせ、見直し用のフラグ、問題一覧、拡大表示、間違えた問題の解き直し、苦手な問題を優先して出題、テストの中断と再開、成績の履歴 |

成績は各端末のブラウザ（localStorage）に保存されます。端末どうしで同期はされません。

### 合格予想の計算方法
正答数 c と誤答数 w から、実力（正答率）を Beta(1+c, 1+w) として推定します。そのうえで、本番の問題数 N（A-1は30問、A-2は25問）で何問正解するかをベータ二項分布で求めます。
- 合格予想点数 ＝ 推定正答率 × 100
- 合格率 ＝ 本番で 60% 以上（A-1は18問、A-2は15問以上）正解する確率

## GitHub Pages で公開する手順

```bash
cd RISS
git init
git add .
git commit -m "支援士 科目A ドリル"
git branch -M main
git remote add origin https://github.com/<ユーザー名>/riss-quiz.git
git push -u origin main
```

GitHub のリポジトリで **Settings → Pages → Branch: `main` / `/(root)`** を選んで保存すると、数分後に
`https://<ユーザー名>.github.io/riss-quiz/` で開けるようになります。
iPhone・iPad では Safari の「共有 → ホーム画面に追加」で、アプリのように起動できます。

ローカルで試す場合：`python3 -m http.server` を実行して http://localhost:8000 を開きます。

## ファイル構成

```
index.html / style.css / app.js   アプリ本体
data.js                           回ごとの正解データ（IPA の解答例から作成）
categories.js                     問題ごとの分野（IPA シラバスの中分類をもとに整理）
img/<回>/qNN.png                  問題画像（IPA の問題 PDF から1問ずつ切り出し）
tools/                            画像を作るスクリプト（再生成するときだけ使用）
```

### 問題データの作り方（参考）
IPA の問題 PDF はスキャン画像なので、文字を取り出せません。そこで次の手順で作っています。
1. PDF の各ページを 200dpi の画像にする
2. macOS の Vision OCR（`tools/ocr.swift`）で「問N」の位置を見つける
3. `tools/build.py` で1問ずつ切り出す

全330問について、切り出した画像が正しい問題番号で始まっていることを OCR で確認済みです。
